# 高颜值质量规范（QUALITY rubric）

> 版本：v0.3  日期：2026-06-28  配套：`DESIGN.md` v0.3
>
> 本文件是整个引擎的**心脏**——它把抽象的"高颜值"翻译成**可执行的检查项**。它同时是三样东西：
> 1. **生成端约束**：写进艺术总监 / 创作轨 / 结构轨模板的提示词与硬规则。
> 2. **评论官检查清单**：身份评论官与页面评论官逐条比对的依据（`ppt_engine/artdirect/identity_critic.py`、`ppt_engine/critic/*.py`）。
> 3. **验收标尺**：判断"做没做到高颜值"的唯一客观标准。

---

## 0. 总则

### 0.1 高颜值 = A 层（地板）+ B 层（天花板）
- **A 层 · 体系纪律**：可机器判定，是地板。本规范的绝大部分是 A 层。
- **B 层 · 艺术指导**：靠视觉模型判定，是天花板。本规范末尾少量评分项是 B 层。
- **第一性原理**：AI deck 丑在 A 层塌，不在 B 层弱。故 A 层是 `error`（阻断），B 层是 `score`（趋势）。

### 0.2 递归适用（两层级）
| 层级 | 评论官 | 检查对象 | 章节 |
|---|---|---|---|
| **身份层** | 身份评论官 | 现场生成的设计语言（spec_lock 候选） | §1 |
| **页面层** | 页面评论官 | 每页排版后的已测原语 + 截图 | §2 |

### 0.3 评级
- **`error`**：阻断。必须修正/重生成才放行。
- **`warning`**：提示。能改则改，否则记录放行。
- **`score`**（仅 B 层美学）：0–1 打分，低于阈值触发重生成建议。

### 0.4 测量来源（三种）
- **`[token]`**：读现场生成的 spec_lock 令牌（身份层）。
- **`[prim]`**：读浏览器量出的已测原语（`measure.py` 的 `fontSizePx/color/x/y/w/h/lineHeightPx/letterSpacingPx/...`）——**客观、零模型、快**。
- **`[shot]`**：读页面截图，交视觉模型（仅 B 层与少量需视觉判断项）。

> 设计取向：**尽量把检查前移到 `[token]` 与 `[prim]`**（可机器判定），`[shot]` 只留给真正需要眼睛的 B 层。

## 1. 身份层 rubric（身份评论官 · 校验生成的设计语言）

输入：艺术总监产出的 `SpecLockCandidate`。全部 `[token]`，机器可判定。**任一 error 不过 → 退回艺术总监修正/重生成（≤N 轮）。**

### 1.1 字阶（Type Scale）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| ID-TS-1 | 模块化 | 相邻档比值落在 {1.2, 1.25, 1.333, 1.5, 1.618} 任一附近（容差 ±0.03），全表共用一个比例 | error |
| ID-TS-2 | 档数克制 | 字阶档数 ≤ 6（display/h1/h2/body/caption/micro） | error |
| ID-TS-3 | 标题↔正文对比 | `display / body ≥ 3.0`（大字要够大，制造层级） | error |
| ID-TS-4 | 正文可读 | `body ∈ [18, 34] px`（按 delivery：text≈20 / balanced≈24 / presentation≈32） | warning |

- ❌ 反例：`{96, 72, 40, 28, 22, 20, 18, 16}`（8 档、比值忽 1.33 忽 1.1，无统一比例）。
- ✅ 正例：`{88, 53, 32, 20}` 比例≈1.65（golden 近似），display/body=4.4。

### 1.2 配色（Palette）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| ID-CL-1 | 结构成立 | 恰好含 1 主色 + 1–2 辅/强调 + 一组中性（≥3 档灰/纸）；强调色 ≤ 2 | error |
| ID-CL-2 | 60-30-10 | 估算主导中性:次色:强调 面积配比近似 60:30:10（用各色"角色权重"近似） | warning |
| ID-CL-3 | 正文对比 | 正文色 vs 底色 对比度 ≥ 4.5:1（WCAG AA）；大字 ≥ 3:1 | error |
| ID-CL-4 | 禁纯黑纯白 | 文本不得为 `#000000`，底不得为 `#FFFFFF`（用染色深/暖纸） | warning |
| ID-CL-5 | 强调克制 | 强调色不进入正文/大面积底；仅用于焦点/语义 | error |
| ID-CL-6 | 图像处理统一 | 声明了一种全局图像处理（duotone / screen-print / grayscale / 原色），deck 内一致 | error |

- ❌ 反例：5 个高饱和原色平均使用、`#000` 正文 on `#FFF`、强调色铺整页底。
- ✅ 正例（zine）：纸 `#F5EFE0` + 墨蓝 `#1E4DBC`(主) + 荧光粉 `#FF5C8A`(强调) + 暖灰中性；图像 duotone。

### 1.3 字体（Fonts）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| ID-FT-1 | 字族克制 | 总字族 ≤ 2（显示体 + 正文体；等宽可作第 3 仅用于代码/编号） | error |
| ID-FT-2 | 角色清晰 | display_font 与 body_font 角色分明（衬线×黑体 / 高对比×常规 等） | warning |
| ID-FT-3 | CJK 完整 | CJK 字体覆盖目标语言全字集（思源系满足） | error |
| ID-FT-4 | 可嵌入 | 选用字体可子集化嵌入（许可证允许）；列入嵌入清单 | error |

### 1.4 网格与母题（Grid & Motifs）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| ID-GR-1 | 间距标尺 | 间距来自统一标尺（如 8pt 网格的倍数）；安全区/列数已定义 | error |
| ID-MT-1 | 母题引用令牌 | 每个生成母题只引用令牌变量，不内联离板 HEX / 离阶 px | error |
| ID-MT-2 | 母题可测可编辑 | 母题组件叶子带 `data-ppt`；文本为真实文本节点 | error |

## 2. 页面层 rubric（页面评论官 · 校验排版后的页）

输入：浏览器排版后的**已测原语**（`[prim]`）+ 截图（`[shot]`）。结构轨主要靠 §2.1–2.4（`[prim]`），创作轨另过 §2.5（`[shot]`）。

### 2.1 几何完整性（最硬地板，全 `[prim]`）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| PG-GM-1 | 不越界 | 每叶子 `x≥margin ∧ x+w≤W-margin`，y 同理 | error |
| PG-GM-2 | 不重叠 | 同层（同 z）非装饰叶子两两不相交（`data-ppt-deco` 除外） | error |
| PG-GM-3 | 文本不溢出 | 文本原语 `h ≥ ceil(text/行容量)×lineHeightPx`（浏览器已折行，等价校验包围盒） | error |
| PG-GM-4 | 不贴边 | 内容包围盒四周留 ≥ 安全区；焦点元素不顶画布边 | warning |

> 浏览器已保证大部分几何正确；本组是把"浏览器算出的真实几何"再断言一遍，构成可证地板（替代确定性）。

### 2.2 字体排印（`[prim]`）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| PG-TY-1 | 字号合规 | 每 `fontSizePx` ∈ 锁定字阶档（容差 ±0.5） | error |
| PG-TY-2 | 行高 | 正文 `lineHeightPx/fontSizePx ∈ [1.4, 1.8]`；大标题 ∈ [1.0, 1.25] | warning |
| PG-TY-3 | 大字收字距 | `fontSizePx ≥ 48` 时 `letterSpacingPx ≤ 0`（负字距收紧） | warning |
| PG-TY-4 | 中西混排·盘古之白 | CJK 与拉丁/数字相邻处有 ~0.25em 间隙（生成端用混排处理；评论官抽查文本是否粘连） | warning |
| PG-TY-5 | 禁孤行寡行 | 段落末行非单字成行；标题不在末尾断成单字（`[prim]` 行宽估算 + `[shot]` 兜底） | warning |
| PG-TY-6 | 字族合规 | 每 `family` ∈ 锁定字族集 | error |

- ❌ 反例：正文出现 `21px`（非字阶档）、行高 1.0 挤成一坨、88px 标题正字距散开。
- ✅ 正例：全页字号 ∈ {88,32,20}、正文行高 1.6、大标题字距 -1。

### 2.3 空间与构图（`[prim]` + `[shot]`）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| PG-SP-1 | 留白比 | 内容包围盒面积 / 画布 ∈ [0.45, 0.82]（太满=拥挤，太空=失衡）；anchor 页可低至 0.30 | warning |
| PG-SP-2 | 唯一焦点 | 存在一个最大/最强元素主导视觉（字号或面积显著领先），`[shot]` 确认 | warning |
| PG-SP-3 | 一页一意 | 文本块数与总字数在角色预算内（dense≤多、breathing 少） | warning |
| PG-SP-4 | 网格对齐 | 主要叶子左/右/中边缘吸附到列网格（容差 ≤ 4px） | warning |

### 2.4 色彩与系统性（`[prim]`，跨页）
| ID | 检查 | 信号/阈值 | 级别 |
|---|---|---|---|
| PG-CL-1 | 颜色合规 | 每 `color`/`fill` ∈ 生成令牌集（含派生透明度） | error |
| PG-CL-2 | 对比达标 | 文本 vs 其实际底色对比度 ≥ 4.5:1（大字 ≥3:1）；用 `[prim]` 的 color + 下层 rect fill 计算 | error |
| PG-CL-3 | 强调克制 | 强调色文本/填充面积占比 ≤ 阈值（不滥用） | warning |
| PG-CS-1 | 跨页一致 | 全 deck 字体集、字阶、配色稳定（无逐页漂移）；spec_lock 逐页重读保证 | error |
| PG-CS-2 | 节奏 | anchor/breathing/dense 分布合理（不全 dense） | warning |

### 2.5 B 层美学评分（`[shot]`，视觉模型，创作轨重点）
结构化输出，每项 0–1，低于阈值给重生成建议（非硬阻断）：
| ID | 维度 | 期望 | 阈值 |
|---|---|---|---|
| PG-AE-1 | 层级清晰 | 一眼知道先看哪、再看哪 | ≥ 0.7 |
| PG-AE-2 | 构图平衡 | 重量分布稳，不头重脚轻/空一半 | ≥ 0.7 |
| PG-AE-3 | 设计感 | "像被设计过"，非 python-pptx 直糊 | ≥ 0.7 |
| PG-AE-4 | 艺术指导大胆度（创作轨） | 有招牌母题/戏剧性，贴合主题 | ≥ 0.6 |
| PG-AE-5 | 身份贴合 | 视觉语言与主题气质相符 | ≥ 0.7 |

## 3. 两个评审基准（架构验证 + 回归锚）

### 3.1 B 层天花板基准 · Indie Bookstore Zine Guide
**用法：基准而非固定模板。** 验证"艺术总监为该主题现场生成 Riso 语言 → 过身份层 §1 → 创作轨复刻套印错位封面 → 过页面层 §2"。逐条对照（取 ppt-master 实际 spec_lock 为参照系，但要求我们**自己生成**且**可编辑**）：

| 项 | ppt-master 实际值 | 我们的要求 |
|---|---|---|
| 身份 §1.2 配色 | 纸#F5EFE0 / 蓝#1E4DBC / 粉#FF5C8A | 现场生成一套同等贴合且过 ID-CL-* |
| 身份 §1.1 字阶 | cover 88 / hero 64 / body 20 | 过 ID-TS-*（模块化、对比 ≥3） |
| §1.2 图像处理 | duotone / screen-print | 过 ID-CL-6（统一） |
| 母题 | 套印错位、半调网点、硬边无圆角 | 生成母题过 ID-MT-*（带 data-ppt、引用令牌） |
| **可编辑性**（我们 > ppt-master） | 颜色写死 HEX | 颜色 ∈ 令牌 → schemeClr 可换肤 |
| 封面页 §2 | — | 过 PG-GM-*/PG-TY-*/PG-AE-*（大胆度 ≥0.6） |

> 通过 = 我们能**自己长出**一套同样贴合、同样惊艳、但**还原生可编辑、且过 A 层纪律**的设计语言。这是整套架构的最高验证。

### 3.2 A 层基准 · 企业增长复盘
KPI / 图表 / 要点 / 对比 四类结构页。要求：结构轨 + 结构评论官**零越界/零重叠**（PG-GM-*）、字号∈字阶（PG-TY-1）、跨页一致（PG-CS-1）、图表为原生对象可改数据。验证 A 层地板在朴素内容上稳。

## 4. 附录

### 4.1 预置 seed 主题（可选起点 / 兜底，非默认锁定）
来自 `ppt_engine/theme.py`，作为艺术总监的可选 `seed_theme`：
- **editorial**：暖纸 `#F5F0E6` + 思源宋体 + 朱砂 `#C0392B`（衬线×黑体，编辑部气质）。
- **aurora**：商务靛蓝 `#4F46E5` + 思源黑体（科技/汇报）。
- **ember**：暖橙红 `#E11D48`/`#F97316`（活力/营销）。

### 4.2 阈值速查
| 项 | 阈值 |
|---|---|
| 字阶比例 | {1.2, 1.25, 1.333, 1.5, 1.618} ±0.03 |
| 字阶档数 | ≤ 6 |
| display/body | ≥ 3.0 |
| 正文行高 | 1.4–1.8 |
| 大标题行高 | 1.0–1.25 |
| 正文对比 | ≥ 4.5:1（AA） |
| 大字对比 | ≥ 3:1 |
| 字族数 | ≤ 2（+1 等宽） |
| 强调色数 | ≤ 2 |
| 留白比 | 0.45–0.82（anchor 可低至 0.30） |
| 网格吸附容差 | ≤ 4px |
| 美学评分阈值 | ≥ 0.7（大胆度 ≥0.6） |
| 评论官重生成上限 | ≤ N 轮（建议 2） |
