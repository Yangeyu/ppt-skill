本 look 的叙事与组织纪律 —— 经典深红咨询风(crimson):

页面解剖(内容页自上而下四段式,缺一段就是薄页):
1. title —— 完整 **SCR 结论句**:主语+判断+(若有)数字后果,≤40 字,读标题即读懂整页
   (对:"头部达人缺位使单篇互动上限被锁死——本品最高仅 4689";错:"达人结构分析")。
2. lead —— **叙事段,内容页必填**:1~2 句连贯正文(60~110 字),交代本页语境、
   竞争背景或"为什么重要",像报告正文一样可通读;素材里章节导语/过渡段落优先
   逐字化用到这里。禁止复述 title,禁止提前说出 so_what。
3. 证据主体 —— 本页信息核心,密度要足(数据表现节)。
4. so_what(chart 用 takeaway)—— **二阶推论**:由本页证据支撑、但不显而易见的
   引申含义或行动指向;禁止复述 title,禁止重复页面上已有的数字。

叙事声音:
- 语气克制、证据先行:每个判断都要有页内数字/事实支撑,形容词能删则删。
- 章节 section 的 title 用短名词短语、subtitle 用英文短语——正文页下判断,章节页只导航。

故事线先行(dot-dash,写 deck 前必做):
- 先把全部内容页的 title 按顺序列出来连读:只读标题应是一段通顺、不重复的完整论证
  (横向逻辑)。连读不通 = 调页序或改标题,然后才动手写页面。
- 同一判断全篇只许出现一次:两页标题表达同一结论,就合并成一页 exhibit,不要摊薄。
- 一页一论点:title 里出现两个判断("…且…""…同时…")就拆页。
- 页内每个模块(含 lead)都必须能连回本页 title(纵向逻辑),连不回去的删掉。

deck 弧线(内容组织):
- 金字塔:先给答案再论证。hero 封面 → toc(desc 写各章一句话结论,不是章节名罗列)
  → **执行摘要页(第 3 页)** → 若干章,每章 = section 幕 + 2~4 页证据 → 建议/行动
  → quote(升华一句)→ closing。
- 执行摘要页承载全篇统领结论(governing thought):title 写全 deck 最重的那一个判断,
  素材有硬数字时用 exhibit(主图放最硬证据,insights 写 2 个关键发现,implications
  给行动方向),偏定性时用 pillars。标准:高管只读这一页也能做决策。
- 章节 section 约每 6 页一幕(短 deck 最多 3 幕);章节骨架跟着素材本身的论证
  结构走,素材有几个论证板块就开几幕,不要为凑上限硬合并。
- **覆盖充分优先于精简**:报告的专业性靠丰富的证据页支撑——素材的每个子小节
  都应有自己的页面,宁可拆页也不要把多个论点挤进一页;页数配额要用满。

数据表现(图表优先——这是本 look 的证据纪律):
- **有数字支撑的论点一律用数据版式承载**,选型跟着 message 走:
  论证主线/一页式论证 → exhibit;单一对比/趋势/份额 → chart;多对象多维对照 → table;
  体量/规模级大数字 → kpi(4 个,尽量带 delta)。bullets/icon_grid 只留给定性并列内容,
  且 bullets 尽量配 emphasis 分层——不要让页面只剩三行字。
- **exhibit 是每章主论证的默认密度**(全篇 ≥3 页,含执行摘要):主图表放最硬的数字
  证据,side 放结构对比条(本品/主体条 em:true),insights 写两个编号解读,
  implications 给 3~4 条行动含义,source 必填数据来源。
- **图表选型跟着数据形态走,全篇类型 ≥3 种(机器复核,整本柱状图 = 不合格)**:
  量级对比 → column/bar;占比/份额/构成比 → donut 或 pie(主体分块放首位上深红);
  层级结构/堆叠构成(如达人分层、内容类目) → stacked_column 或 stacked_bar;
  多对象多维画像对比(3~6 维) → radar,**仅当素材本身给出各维数值/占比时可用,
  禁止自行指数化打分**(编数会被事实评论官退回);趋势/走势 → line。
- chart 证据页三件套必填:subtitle 写单位·口径·周期(如"篇 · 2026年1—7月 · 千瓜数据"),
  note 点名要读者看的那根柱/那条线(带原数),source 写数据来源;
  series 首名放主体(本品),让唯一的深红强调落在主体上。
- insights 洞察框:title 写短判断(≤24 字),**不要带 ①②/1. 编号**——红色徽章会
  自动编号;points 每点一个事实,最关键的数字词组用 **…** 标出(渲染深红加粗)。
- table 列数≤5、单元格短文本;数字带单位;素材缺的数据用"--",不要编;source 写来源。
- kpi 的 label 写清口径(如"商业笔记数 2025.01-10");delta 只在素材有环比/同比时给。

强调标记:
- 标题/金句里最关键的 1 个词组可用 **词** 标记(渲染成深红),每页最多一处;
  insights 的 points 里可另标关键数字(每点最多一处);
  其他字段(lead/so_what/lines/desc 等)不要用 **。

结构约定:
- 第 1 页 hero(prompt 描述与主题相关的纪实场景画面,facts 给 3 个最硬的数字),
  第 2 页 toc,第 3 页执行摘要;倒数第二页 quote,最后一页 closing。
- hero/cover 的 title 是大字排版、单行不折:**≤16 字**(副题放 subtitle),
  否则会溢出画布。
- icon_grid 至少 4 格,素材足够时填满 6 格(2~3 格会显得页面空)。

红线:
- 标题是名词短语的内容页 = 不合格;内容页缺 lead 叙事段 = 不合格;
- so_what 复述标题或页面已有数字 = 不合格;
- 有数字支撑的论点放进 bullets/icon_grid = 不合格(升格为 chart/exhibit/kpi/table);
- 全篇图表只有一种类型 = 不合格(按数据形态路由 donut/stacked/radar/line);
- 两页标题表达同一判断 = 不合格(合并成一页);证据装不下就拆页,不要硬塞;
- 素材子小节被整段跳过或多论点挤进一页 = 不合格(页数配额用满,覆盖优先);
- 没有执行摘要页的 deck = 不合格。
