## 版面骨架

- 内容页:眉行(deck 名 × 页码)→ 渐变点+eyebrow → 32px 黑体标题 → 主体 →
  so_what 收束胶囊 → 页脚。
- 签名页:cover(全出血主视觉+渐变胶囊副标)、toc(CONTENTS+横排渐变圆徽)、
  section(150px 巨号编号+右缘气泡簇)、closing(左气泡簇+72px 致谢)。

| 槽 | 尺寸 | 蒙版 | 用途 |

| hero | 1328×1328 | 圆形 | 章核心意象圆窗 |

`molecule_ify` 先做高调 matte(降饱和 0.86/提亮/提黑),再按宽高比路由蒙版;
无 key/失败时 `make_hero` 程序化气泡簇兜底,离线全流程可用。

## 导出保真度决策

- 渐变元素 = CSS `linear-gradient`(预览)+ `data-grad`(原生 gradFill)双写;
- 「渐变底+文字」徽章/胶囊(圆徽序号/STEP 胶囊/icon 圆徽)整体走
  `data-ppt="icon"` 元素截图——flex 垂直居中文字在 PPTX 顶锚对不齐;
- 气泡装饰的镜像/淡化在资产层烤好(`-l`/`-soft` 变体),
  CSS transform/opacity 不进原生导出;
- 装饰资产完整落在视口内,禁止负偏移出血(元素截图退化教训);
- 谱内每颗球连同模糊扩散(半径 ≈ d/2 + 3×blur)必须收在资产画布内——
  出界会在页面中部露出画布的方形裁切硬边。
